# Strive

Strive is a gym tracker built with the MERN stack. Log workouts, track your progress, and stay motivated with AI-generated quests, streaks, momentum and a leaderboard.

**Live app:** https://strive-frontend-1.onrender.com/ (deployed on Render, installable as a PWA for use in the gym)

## Features

### Workouts
- Build workouts from a seeded exercise library, with sets that track weight, reps, duration or distance depending on the exercise's tracking mode
- Rest timer and workout timer while you train
- Previous workouts list, with the ability to delete workouts
- Workout summary on completion: stats, personal bests, muscle group radar graph and Strive points earned
- Metric / imperial unit preference

### Progress
- Total and monthly progress cards, training calendar and per-exercise progress charts
- Personal best tracking and estimated one-rep max
- Muscle group split and heatmap

### Games
- **Quests** - daily, weekly and monthly challenges generated by Anthropic's Claude from your recent workout history. Quest types are `strength`, `consistency`, `volume` and `progressive`, and each completed quest awards Strive points (100 daily / 500 weekly / 1000 monthly)
- **Levels and Strive points** earned from workouts, personal bests and quests
- **Streaks** with streak-increased / streak-broken updates
- **Momentum** (0-100) that rises with workouts, PBs and quests and decays the longer you're away
- **Leaderboard** to compare with other users

### Accounts
- Register / login with JWT authentication
- Guest mode, with a migration flow to move guest data into a new account
- Onboarding, profile editing, account reset and deletion

## Getting Started

### Prerequisites
- Node.js (CI uses v24)
- A MongoDB database (local or Atlas)
- An Anthropic API key (needed for quest generation)

### Install
```bash
git clone https://github.com/Benpsheppard/strive.git
cd strive
npm install
npm install --prefix strive-backend
npm install --prefix strive-frontend
```

### Configure environment

Create `strive-backend/.env`:

```env
NODE_ENV=development          # development | production | test
PORT=8000
MONGO_URI=mongodb://...
MONGO_URI_TEST=mongodb://...   # database used when NODE_ENV=development
JWT_SECRET=<at least 32 characters>
FRONTEND_URL=http://localhost:3000
ANTHROPIC_API_KEY=sk-ant-...
```

In development (`NODE_ENV=development`) the server connects to `MONGO_URI_TEST` instead of `MONGO_URI`, and exits if it isn't set. The server also exits on startup if `NODE_ENV`, `PORT`, `MONGO_URI`, `JWT_SECRET` or `FRONTEND_URL` is missing. In production `JWT_SECRET` must be at least 32 characters and `FRONTEND_URL` must be a valid URL.

Create `strive-frontend/.env`:

```env
VITE_API_URL=http://localhost:8000
```

> The Vite dev server proxies `/api` to `http://localhost:8000`, so use that port for local development.

### Seed the exercise library
```bash
cd strive-backend
node scripts/seedExercises.js
```
Upserts exercises by slug, so existing workouts keep valid references. Seeding with `NODE_ENV=production` requires `--allow-production`.

### Run
```bash
npm run dev
```
This starts the API and the Vite frontend together. Open http://localhost:3000.

| --- | --- |
| `npm run dev` | Run backend and frontend together |
| `npm run server` | Backend only |
| `npm run client` | Frontend only |
| `npm run build` | Build the frontend for production |
| `npm test` | Run the backend Jest tests |

Lint the frontend with `npm run lint --prefix strive-frontend`, and run its Vitest tests with `npm test --prefix strive-frontend`. CI runs the backend tests, then the frontend lint, tests and build.

## API Overview

All routes are under `/api`. Everything except register, login and the exercise library (`GET /api/exercises`) requires an `Authorization: Bearer <token>` header.

| Prefix | Purpose |
| --- | --- |
| `/api/users` | Register, login, `me`, profile, unit preference, momentum, streak checks, guest migration, reset, delete |
| `/api/workouts` | Create, list and delete workouts, plus add an exercise to a workout |
| `/api/exercises` | Exercise library |
| `/api/quests` | `GET /` list quests, `POST /generate/:duration` (`daily`, `weekly`, `monthly`) |
| `/api/leaderboard` | Leaderboard rankings |

Login, registration and quest generation have their own stricter rate limits on top of the general 500 requests / 15 minutes limit.

## Testing

Backend tests live in `strive-backend/__tests__` and cover controllers, quest generation and models, workout services and summaries, the leaderboard and security. They run on every push and pull request via GitHub Actions (`.github/workflows/tests.yml`).

## Deployment

In production (`NODE_ENV=production`) the Express server serves the built frontend from `strive-frontend/dist`, so run `npm run build` before starting the server. The app is hosted on Render, which is why `trust proxy` is enabled for accurate rate limiting.
